Entity Engine 流程图

Entity engine 是独立的二次处理工具：它只读已经由 tag/template workflow 产出的 todo/TM workbook， 拆出可复用实体结构和实体词表，再把完成后的 entity 结果合并回完整 todo workbook。

不调用 tag_engine / template_engine

输入

Target Todo Workbook

上游已预处理，entity engine 只读取 to_translate.source_unit。

  • sheet: to_translate
  • 关键列: unit_id, source_unit, target_unit

TM Reusable Units Workbook

同样是预处理后的 TM，不是原始 workbook。

  • sheet: tm_pairs
  • 关键列: source_unit, target_unit

拆分和抽取

entity-split

从 target todo 中找可复用 entity structure，把文件拆成两条可并行处理的线。

entity_related_workbook target_entity_structures target_entity_terms _entity_map
not_entity_related_workbook 保留普通 to_translate rows 给其他 workflow 并行处理

entity-extract-tm

从 TM 的 tm_pairs 中抽出可复用结构和实体译文，形成 entity TM。

TM_entity_structures source_structure target_structure
TM_entity_terms source_entity target_entity

预填和人工确认

entity-prefill

TM 只填 entity workbook 里的结构表和实体表，不直接写 target todo 的 target_unit。

  • source_structure 命中后填 target_structure
  • source_entity 命中后填 target_entity
  • 状态仍由人工决定是否进入 ready

人工确认

PM 或译员只需要看两张主表。

target_entity_structures source_structure target_structure status
target_entity_terms source_entity target_entity status

安全门

ready结构和所有实体都 ready，才允许进入 entity-fill。

回填和合并

entity-fill

把 ready 的结构和实体组合成当前行的 target_unit，只写 entity-related workbook。

  • 结构未 ready：不填
  • 实体缺译文：不填
  • 实体未 ready：不填

entity-merge

把 entity-related 结果和 not-entity 文件按 original_index 合回完整 todo workbook。

  • entity 行使用 entity-fill 结果
  • 非 entity 行使用其他 workflow 结果

Existing PhraseLoom fill

合并后的 todo workbook 再交给现有 fill 流程写最终目标文件。

TM prefill 填哪里

只填 target_entity_structures 和 target_entity_terms，不直接填完整 todo 的 target_unit。

entity-fill 填哪里

只在结构和实体都完成且 ready 后，才把组合结果写入 entity-related workbook 的 target_unit。

非 entity 内容

不在 entity engine 里翻译。它被拆到独立 workbook，可以由普通翻译流程或其他 workflow 并行处理。
