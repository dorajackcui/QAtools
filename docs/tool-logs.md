# 六个新工具的运行日志

Master → 小表、小表 → Master、列操作、兼容性重存、同名文件替换、未翻译统计，
均在页面底部左侧提供【查看日志】。点击打开独立小窗口，运行时可以随时关闭、重新打开；
不会暂停或取消后台任务，也不阻止操作主窗口。

- 每个文件处理完成后显示一行：状态、相对文件名和关键计数。例如
  `[已更新] a.xlsx · 匹配 120 行，更新 35 格`；统计显示未翻译量/总量、未翻译行/总行数。
  不再逐文件追加“正在处理”、输出路径、整段内部字段或每千行进度。
  输出位置与备份目录每次任务仅显示一次，最后给出一行汇总；主页面进度条继续更新。
- 失败、兼容性重存失败、跳过原因仍保留；同步冲突和未找到的身份按需额外列出。
  完成后仍可查看本次日志，并使用【复制日志】复制当前保留内容。
- 日志只保留在本次应用会话内；同一工具开始下一次任务时清空上次日志。
  内容同步的两个方向分别保留日志，切换 Tab 不会清空。
- 文件处理在后台线程进行；日志通过有界队列传递，GUI 每 100 ms 分批刷新，单次最多
  100 条、约 32 KB 文本。日志积压超过 10,000 条时丢弃较早记录并提示省略数量，
  单条过长时截断；窗口保留最近 10,000 行，避免大量日志拖慢界面。
- 浏览较早日志时不会强制滚到末尾；回到末尾后继续自动跟随。

## 输出目录

不再自动生成 `content_sync_report.json`、`qatools_tool_report.json` 或日志文件。
新输出目录为可选项，留空时在输入位置保存结果，填写新目录时另存；各工具的具体保存对象见工具 README。
处理后的工作簿、`未翻译统计.xlsx` 和原位替换所需备份仍保留。
业务层仍返回内存中的结果摘要；错误与冲突在 GUI 日志里查看。

同一应用会话会记住本次新建的另存输出目录，递归扫描时排除这些结果子目录；原位处理不会把输入目录标记为输出。
仍兼容识别旧版 report 标记，但不创建新的标记文件。重启后无法自动识别没有标记的历史输出，
因此另存时建议将新目录放在输入目录旁，并选择纯输入目录执行批处理，避免把旧结果混入输入。

原有一键质量检查等工具的报告工作簿保持原来的用途；本次调整只覆盖上述六个工具的附加运行报告。
