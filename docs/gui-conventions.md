# GUI 约定

统一 GUI 使用 PySide6，入口为 `qatools gui`。工具排列见[产品能力地图](../README.md#能力地图)，实现位置见[仓库地图](repository-map.md)。

## 视觉基础

桌面 GUI 采用 [YIZHI 通用视觉参考 1.1](https://dorajackcui.github.io/reference.html)
（2026-09-15），按 QA 工具的紧凑表单密度适配。共用颜色与 Qt 控件状态维护在
[qt_gui_common.py](../tools/qt_gui_common.py)。页面复用共用主题、分组与输入组件。

| 角色 | 统一约定 |
|---|---|
| 工作区 / 辅助区域 | 白色 `#FFFFFF` / 浅灰 `#F7F7F5` |
| 主文字 / 次要文字 | 深灰 `#2F2F2C` / `#707068` |
| 分隔线 / 控件边界 | `#E9E9E5` / `#DEDED8`；输入框为浅灰底，悬停加深边界，编辑时底色变白 |
| 品牌 | 展示名称 `QAtools.` 与各功能页主标题末尾附 `#D97757` 橙色句点；导航、无障碍名称及正文保留原名称 |
| 操作与选中 | 主操作与勾选保留橙色 `#B45B3C`，配白字；次要按钮为浅灰实底与弱边框；导航和 Tab 选中为浅灰底与加粗文字 |
| 输入焦点 | 蓝色 `#2383E2` 仅用于可编辑文本、数字、多行及可编辑下拉输入框 |
| 其他焦点 | 按钮、勾选框、Tab、只读字段与非编辑下拉框使用中性边框或虚线提示，保留键盘定位；橙色主按钮用较深橙色边界 |

优先使用本机 Inter，未安装时保留平台无衬线字体及中文回退，不在线加载字体。
桌面页面标题为 24 逻辑像素、表单与紧凑分组标题为 13，主要层级使用 600 字重；
中文及正文使用正常字距。按钮橙色比品牌句点略深，白字对比度约 4.66:1。
共用面板内边距为 12、控件间距为 8，控件圆角为 4、面板为 6，无装饰阴影。
数字输入框使用无立体边框的细线箭头，悬停时显示浅灰底；保留直接输入、键盘增减和上下限约束。
导航项点击后仅以浅灰底和加粗文字表示选中，不显示焦点虚线；仅键盘导航时显示细灰实线焦点边界。
已有导航、Tab、固定底部操作栏和滚动区域保持各自职责；错误、警告和执行结果仍提供文字反馈。

## 页面与状态

- 启动时先显示主窗口与短暂加载提示，再载入当前工具；其他页面及其业务模块首次使用时加载。
- 已创建页面在主窗口中持久保留，切换导航不会重新构造页面；后台任务与退出保护仅检查已创建页面。
- 内容同步的两个 Tab 分别保存输入、结果和日志；后台任务继续运行。
- 表单不显示常驻解释段落；保留输入标签、占位提示、输出预览和运行状态。
- 底部操作栏固定；导航可滚动，“设置”固定在侧栏底部。
- 小窗口下，表单宽度不足时可横向滚动，右侧输入和选择按钮仍可访问。
- 目录工具的实时日志行为见[运行日志](tool-logs.md)；输入/输出规则仍分别见工具 README。

## 选列预览

需要填写列字母、列索引或表头的页面，在手动选择文件或文件夹后自动弹出“预览并选择列”；
内容同步在原有选择检查结束后分别弹出 Master 和小表预览。窗口后台读取 `.xlsx/.xlsm`，
显示首行表头及随后 5 行、原始行号和 `A (1)`、`B (2)` 等列标，可横向滚动。
在预览下方的下拉框中选择 Source、Target、Key 等所需列，点击“使用所选列”回填页面；
取消不应用弹窗中的修改。需要重新选列时，再次选择同一文件或文件夹即可。预览只读原始值，不加载样式、不计算公式，
单元格文字最多展示 1,000 字符；按表头名称回填时仍使用完整表头，不模拟 Excel 的日期及数值显示格式。

文件输入按页面选择的工作表预览；工作表留空时使用活动表。PhraseLoom 按其业务规则
预览第一张工作表，选列后按数字索引回填。
文件分组按实际表头名称回填原文和译文列；
其他工具按列字母回填。文件夹输入递归列出候选，随机抽取一份 `.xlsx/.xlsm`，窗口显示实际
文件路径；忽略锁文件、备份及可识别的结果目录，并排除对应工具的 Master、输出树或
保留统计表。除固定第一张表的 PhraseLoom 外，预览中可切换工作表；文件夹的“各文件活动工作表”
选项保持页面工作表留空，不会把随机样本的活动表名称强制应用到全部文件。

恢复选项、仅程序化填入路径和构造页面不会触发预览读取。每次手动选择输入重新读取，输入或工作表变化
会关闭旧预览并丢弃尚未完成的旧结果。读取在后台运行，只解析工作表头部，限制工作表
XML 为 2 MiB、共享文本为 8 MiB；超出时保留已读部分并显示提示，不遍历整张表。
旧 `.xls/.xlsb` 不启动 Excel 做预览；只有这些格式的目录会提示无可预览文件。

## 表头别名

一键质量检查和法语 NBSP 页面从工作表首行自动识别 Source / Target 列。
在侧栏“设置”中为 Source 和 Target 分别填写别名，每行一个。

- 忽略大小写及首尾空白，精确匹配整个表头；`Source` 不匹配 `SourceFile`。
- 自定义别名优先于内置 `source` / `target`；未命中自定义别名才使用内置表头。
- 同级别匹配多列或没有匹配时清空对应列、显示“请指定”，由用户填写列字母。
- 设置持久化到当前用户；保存后重新识别已经加载的 QA / NBSP 工作簿。
- 这不是所有工具的列规则：内容同步与未翻译统计手动指定列；PhraseLoom 使用自己的表头/索引参数。

实现：[header_aliases.py](../tools/header_aliases.py)、[excel_metadata.py](../tools/excel_metadata.py)。
QA 的“记住选项”是独立配置，保存范围与恢复行为见 [workflow README](../tools/workflow/README.md#使用)。
