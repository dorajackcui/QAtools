QAtools 使用指南

从质量检查到内容同步，在同一个本地工具箱中完成 Excel 翻译处理。 本页使用当前界面截图，按操作步骤说明输入、选项与结果；详细规则链接各工具文档。

一键质量检查 · 快速上手

  1. 打开页面启动 QAtools，在左侧“常用流程”选择“一键质量检查”。
  2. 选择 Excel选择输入文件；GUI 会读取工作表并尝试识别 Source / Target 列。
  3. 确认范围确认工作表、两列字母和开始行；再按需要调整检查项目。
  4. 开始检查点击右下角“开始检查”，完成后按提示路径打开生成的报告。
记住当前选项

点击“记住选项”保存当前输入路径、工作表、列、开始行及全部检查与详细设置。下次打开恢复这些选择，但不会读取 Excel 或自动执行；以后调整需再次点击才会保存。保存范围

默认输出无需另选路径

选择输入文件后，页面会预览 workflow_check_原文件名.xlsx；报告生成在输入文件同目录。

输入与范围

界面项作用建议
输入 Excel 选择待检查的 .xlsx 或 .xlsm 文件。 检查期间保持文件可读写；如提示文件锁定，请先关闭 Excel 中打开的同名文件。
检查工作表 决定本次检查的数据表。选择文件后会自动载入工作表列表。 切换工作表后，GUI 会重新尝试识别 Source / Target 列。
Source 列 / Target 列 填写 Excel 列字母，例如 A、B、AA。 两列不能相同。自动识别失败时可直接手动修改。
开始行 从该 Excel 行开始处理，默认 2。 通常第 1 行是表头；多行表头时改为第一条实际数据所在行。
非标准表头如何自动识别？

点击左侧底部“设置”，在“Excel 表头自动识别”中分别填写 Source / Target 表头别名，每行一个并保存。自定义别名优先；未命中自定义别名时才回退内置 source / target。 匹配忽略大小写和首尾空格；同级匹配多列或没有匹配时清空对应列，显示“请指定”，请手动确认。

仅一键质量检查与法语 NBSP 使用这套表头别名；内容同步和统计需手动配置列。完整规则

术语与翻译一致性

术语检查

默认开启

从选定 mark 中建立新术语对，也可结合历史 TB 回扫全文，定位缺失、错译或映射冲突。

查看术语专项配置 ↓

同 Source 不同 Target

默认开启

按 Source 单元格精确分组；完全相同的 Source 对应多个不同 Target 时报告组内每一行。

同 Target 不同 Source

默认关闭

查找完全相同的非空 Target 是否对应多个 Source。适合发现误复用，但合理复用也很常见。

内容保真检查

Tag / Placeholder

默认开启

比较 Tag、Placeholder 或 memoQ Marker 的内容、次数及尖括号层级结构。

查看 Tag 专项配置 ↓

换行数量

默认开启

比较 Source / Target 的真实换行数。LF、CRLF、CR 都支持；文本 \n 不算真实换行。

数字一致性

默认开启

比较数字表达式及重复次数，不要求顺序一致；自动排除 URL、Tag、Placeholder 等内部数字。

URL 一致性

默认开启

比较 URL 完整文本和重复次数，识别 HTTP(S)、FTP、file、mailto 与 www 开头的地址。

Target 文本质量

Target 中文

默认开启

定位 Target 中残留的汉字、CJK 标点、全角标点和常见中文排版符号。

Target 文本规范

默认开启

检查异常标点、连续空格、首尾空格和全半角混用；四条规则可独立开关。

术语检查设置

两种术语来源可以组合

术语标记默认同时选择中文方括号 【】 与半角方括号 []，从正文显式 mark 中发现新术语对。
历史 TB可选 Excel 术语库。命中历史 Source 时优先采用历史 Target，并与本批新增术语一起回扫全文。
仅历史 TB 模式可以取消两个 mark，但此时必须提供历史 TB；工具只检查已有术语，不新增术语。
历史 TB 范围可确认工作表、Source 列、Target 列和开始行；默认优先选择“术语表”并自动识别列。

TB 项目

“保存当前”可把历史 TB 文件、工作表、列和开始行保存为常用项目；之后从下拉框快速复用。

删除项目只删除 QAtools 中的配置，不会删除原始 TB 文件。

术语报告重点

启用术语检查时，报告会包含“术语表”。它只写本次实际涉及的历史术语和本批新增术语，不复制整份历史 TB。

Tag / Placeholder 设置

常规 Tag（默认）

  • <...> tag
  • [color=...] / [/color] tag
  • {...} / {{...}} placeholder
  • 文本中的 \n mark

memoQ Marker

只检查数字 marker：{n}、{n>、<n}。适合 memoQ 导出的成对数字标记。

常规类型和尖括号过滤配置在此模式下会自动停用。

尖括号过滤配置

可选 JSON 文件，仅在“常规 Tag”且启用 <...> 时生效。 未选择配置时，工具按内置规则检查全部可识别尖括号 Tag。

Target 文本规范设置

异常标点符号报告 ..、,,、。。 等；允许 ...、…，连续感叹号和问号不在本规则中。
连续空格报告任意位置连续 2 个及以上普通 ASCII 空格；NBSP 不计入。
首尾空格报告 Target 开头或结尾的普通 ASCII 空格；NBSP 不计入。
全半角混用仅比较同类字符或标点的半角/全角形式，不把英文与中文标点的正常共存视为问题。

检查报告怎么看

原工作表

输入工作簿中的业务工作表会完整保留，检查结果以新增工作表呈现。

问题处理

同一原始行命中多个检查时只保留一行，检查项和问题描述合并展示。

质量检查汇总

按本次启用的检查列出问题行数，便于快速判断重点。

术语表（可选）

“本批次是否有问题”可筛选，有问题的状态格浅红突出。只统计该术语实际触发的术语问题；修订后需重新检查以更新状态。查看规则。

哪些行会回填？

  • “修改后target”为空：忽略。
  • 修改值与现有 Target 相同：计为内容未变化。
  • 填写了新值且行号对应的 Source 匹配：写入修订稿。

行号与 Source 校验

按行号定位原数据并精确核对 Source；不匹配会跳过并提示。报告里的原 Target 仅供参考，误改或清空不会影响回填；即使原数据 Target 已变化，Source 匹配时仍以“修改后target”为准。完整规则见 修订回填说明。

内容同步 · Master ↔ 小表

在“常用流程 → 内容同步”中切换两个 Tab。二者分别保留配置、结果和日志，切换不会停止后台任务。

Master → 小表

把总表内容写入匹配的小表行，可同步一列或连续多列。Master 来源不修改。

小表 → Master

汇总小表译文后回填总表，仅回填一列。小表来源不修改。

  1. 选择两端选择 Master 文件和小表目录；目录会递归处理。支持 .xlsx / .xlsm。
  2. 确认保存位置新输出目录留空时，正向直接更新小表，反向直接更新 Master。如需副本，填写尚不存在的新目录。
  3. 配置匹配列分别填写 Key、原文、内容列，以及工作表和表头行数。默认 Master B/C/D，小表 A/B/C；核对实际文件，不按表头自动推断。
  4. 确认写入策略按需选择“仅填空”“允许空白写入”；正向还可设置连续更新列数和可选 Excel 重存。
  5. 执行与核对点击“同步到小表”或“回填 Master”，查看更新格数与日志中的失败、未匹配或重复身份信息。
查看小表 → Master 页面
空白与正文保持原意

真实空值不会写成文字 None 或 nan；用户输入的文字 None、nan、NA、NULL 以及首尾空格、换行原样保留。两项写入选项彼此独立，默认均关闭。

按 Key + 原文匹配，不新增行；来源公式缺少缓存不能当空白处理。重复身份、缓存及失败保护以内容同步规则为准。

文件与表格工具

以下三个页面均在“文件与表格”中；Batch 拆分与合并表格的流程见上方工具导航。

兼容性重存

选择工作簿目录，按需填写新输出目录，点击“兼容性重存”。需要桌面 Microsoft Excel；文件保持原扩展名，留空输出目录会直接重存原文件。

失败文件保留原内容，继续其他文件；环境与宏处理规则见兼容性重存说明。

查看兼容性重存页面

列操作

  1. 选择工作簿目录，确认是否填写新输出目录。
  2. 选择清空、插入或删除，填写列字母（默认 C）及工作表。
  3. 清空时设置保留表头行数；插入时填写新列第 1 行标题；点击“执行列操作”。

清空保留格式；插入、删除操作整列，由 Excel 处理引用变化。需要桌面 Excel，详见列操作规则。

同名文件替换

选择替换来源目录和目标目录，确认输出位置后点击“替换同名文件”。它按文件名替换整个 Excel 文件，不合并单元格；来源和目标不可相同或互相包含。

原位替换会先备份目标文件；重名冲突会保留目标并列出候选。备份路径与恢复方法见替换与恢复规则。

查看同名文件替换页面

未翻译统计

在“翻译辅助 → 未翻译统计”选择文件目录，确认原文、译文列及计数口径，点击“生成统计表”。默认 B/C 列、活动工作表、1 行表头、中文字符数。

结果为“未翻译统计.xlsx”，含各文件数据和总计；失败或跳过的文件按需列在“未统计文件”页。旧统计表不会被重复纳入统计。

统计中的文字 nan 计为未翻译，这与内容同步保留原文的口径不同。完整计数范围和公式缓存处理见统计规则。

运行日志与输出位置

新增六项功能的底部“查看日志”打开独立小弹窗。正常文件使用一行摘要，失败或冲突补充必要原因；关闭弹窗不会停止任务，再打开可以继续查看。

处理和日志入队在后台完成，界面定时分批刷新；大量日志会截断较早记录，完整计数仍以结果摘要为准。可复制当前显示日志，详见日志容量与行为。

常见问题

自动识别到了错误的 Source / Target 列
先在当前页面手动填写正确列字母。若项目长期使用特殊表头，在左侧“设置”中保存对应表头别名。
提示“术语检查至少需要一种术语 mark，或一个历史 TB”
重新打开术语设置，至少勾选一种术语标记；或者选择历史 TB 并确认工作表、Source / Target 列。
Tag 或 Target 文本规范无法开始
启用 Tag 检查时必须选定一种模式/类型；启用 Target 文本规范时至少保留一条规则。
“同 Target 不同 Source”为什么默认关闭？
多个不同 Source 合理共用同一译文的情况很常见。只在需要排查误复用时开启，并把结果视为人工复核线索。
运行过程中可以关闭 QAtools 吗？
不可以。后台任务执行时窗口会阻止关闭，以避免输出文件不完整。等待完成提示后再退出。
如何保留多次检查结果？
GUI 使用固定的 workflow_check_原文件名.xlsx。下一次运行前请把旧报告重命名或移动到其他目录。
