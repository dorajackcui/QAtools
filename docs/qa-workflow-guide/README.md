# 说明网页维护入口

`index.html` 是仅介绍 GUI 的离线指南，`guide.css` 负责样式，`guide.js` 标记当前阅读的工具，
`assets/` 保存实际 Qt 页面截图。保留这四部分即可独立阅读，不依赖网络或仓库其他目录；
禁用 JavaScript 后，导航锚点、正文和可展开截图仍然可用。

2026-09-14 已覆盖软件的 12 项工具与设置页。侧栏与 `toolshub_gui.py` 的
`TOOL_GROUPS`、`SETTINGS_ITEM` 保持相同分组、名称和顺序；每项导航只对应一个
带 `data-tool` 的正文区块。一键质量检查的小节目录放在正文内，日志与常见问题作为公共补充。

维护前先读取对应工具 README（入口见[仓库地图](../repository-map.md)）、
[GUI 约定](../gui-conventions.md)及[当前能力地图](../../README.md#能力地图)。
参数、默认值和输出约束以业务文档及实际 GUI 为准；网页按选择输入、运行、查看结果组织，
不添加 CLI 用法。工具增加或导航调整时，同时更新侧栏、正文、截图脚本和图片。

## 视觉风格

沿用 [GUI 视觉基础](../gui-conventions.md#视觉基础)与
[YIZHI 通用视觉参考](https://dorajackcui.github.io/reference.html)，按长文档阅读密度适配：
白底、浅灰导航与辅助区域、深灰正文、细分隔线和小圆角；本机 Inter 优先，中文使用系统黑体。
品牌与功能主标题后缀使用橙色句点，阅读入口保留橙底白字，导航选中使用浅灰底与加粗文字。
链接使用中性细下划线；键盘焦点为灰色实线，鼠标点击不显示焦点轮廓。状态提示保留语义色。
字体与全部页面资源均从本机加载，不新增网络依赖。

## 信息层级

- 每项工具以「名称 + 一句话用途」开头，分类仅在侧栏出现，不重复导航路径。
- 正文先帮助用户选择方向或动作，再按顺序说明操作，随后说明输出与结果。
- 操作步骤使用单列编号列表；匹配、覆盖、输出路径与文件保留规则放在相关步骤附近，保持可见。
- 截图默认折叠；可选配置、边界情况和排错细节按需展开。不要把必读操作限制藏在截图说明里。
- 一键质量检查先呈现「开始检查 → 查看报告 → 应用修订」，输入、检查项目与专项设置作为后续参考。
- 对比选项使用浅灰双栏；一般说明使用留白与细分隔线，避免每段文字都套卡片。
- 本轮沿用 22 张截图，仅整理文案、阅读顺序和网页排版。

## 本地预览

从仓库根目录运行 `python -m http.server 8765 --bind 127.0.0.1 --directory docs/qa-workflow-guide`，
打开 <http://127.0.0.1:8765/#content-sync>。文件修改后刷新页面即可。

## 更新截图

在已安装项目依赖、具备中文字体的 Windows 环境中，从仓库根目录运行：

```powershell
python scripts/capture_gui_guide.py
python scripts/check_docs.py
```

[截图脚本](../../scripts/capture_gui_guide.py)直接构造当前 Qt 页面，通过离屏渲染生成截图，
隔离表头别名、QA 记住选项和 TB 项目配置，不读取或保存用户配置。
日志截图来自临时样本的实际同步，省略开头两条含临时路径的记录；不带入用户文件。
小表目录提醒也由临时样本触发，分别展示正常计数和只读提示；只读属性在拍摄后恢复。
离屏环境缺少自动字体发现时仅加载本机中文字体，不把字体文件提交到仓库。

逐张检查截图的中文字形、控件标签、Tab、页面边界和个人信息；截图更新后核对 HTML 的说明和 alt 文本。
控件布局、标签或操作流程变化时更新对应截图，避免说明与实际操作不符。
2026-09-15 本轮仅统一视觉细节，按确认沿用原有 22 张截图；主标题句点、配色、边框与焦点样式以当前 GUI 为准。
