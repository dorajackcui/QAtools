# 说明网页维护入口

`index.html` 是离线指南，`guide.css` 负责样式，`assets/` 保存实际 Qt 页面截图。
2026-09-10 已同步工具导航、内容同步双 Tab、四项工具、日志及 QA 最新操作。
保留这三个部分即可阅读网页；工具规则和 CLI 手册的相对链接需要完整仓库目录结构。

维护前先读取 [workflow 规则](../../tools/workflow/README.md)、[GUI 约定](../gui-conventions.md)
及[当前能力地图](../../README.md#能力地图)。从实际 GUI 截图，不使用旧页面描述推断当前行为。

## 更新截图

在已安装项目依赖、具备中文字体的 Windows 环境中，从仓库根目录运行：

```powershell
python scripts/capture_gui_guide.py
python scripts/check_docs.py
```

[截图脚本](../../scripts/capture_gui_guide.py)直接构造当前 Qt 页面，通过离屏渲染生成截图，
隔离表头别名、QA 记住选项和 TB 项目配置，不读取或保存用户配置。
日志截图来自临时样本的实际同步，省略开头两条含临时路径的记录；不带入用户文件。
离屏环境缺少自动字体发现时仅加载本机中文字体，不把字体文件提交到仓库。

逐张检查截图的中文字形、控件标签、Tab、页面边界和个人信息；截图更新后核对 HTML 的说明和 alt 文本。
代码或主题变动后重新运行脚本，不能只换页面文案保留过时截图。
