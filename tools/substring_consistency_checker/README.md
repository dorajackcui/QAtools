# 子串译文一致性

可选的一致性扩展检查：当某条完整短 Source 出现在另一条较长 Source 中，检查
长句 Target 是否包含短句的参考 Target。未匹配到时报告疑似不一致，需要人工复核。
语序、词形和上下文变化可能产生合理差异；匹配到也不代表译文正确。

## 入口

一键质量检查 GUI 的“术语与翻译一致性”分组中可勾选“子串译文一致性”，默认关闭。
右侧下拉箭头打开最小有效字符数设置。支持“全选 / 清空”、记住选项和统一报告中的修订回填。
CLI 检查值为 `substring-consistency`，调用见 [CLI 手册](../../docs/cli-usage.md#一键质量检查)。

## 规则

- 仅检查选中工作表和开始行之后的 Source / Target，不跨工作表建立关系。
- 本次同时启用术语检查时，复用其实际使用的历史 TB 与本批次新增术语词库。
  完整 Source 经共享归一化并忽略大小写后，若等于某个有非空参考 Target 的 Source
  术语，则整条排除：既不作为子串建索引，也不作为母串扫描，与该行实际译文是否正确无关。
  该术语的错译仍由术语检查报告。仅包含术语或仅 Target 等于某术语的行不排除，
  也不按术语的复数变体或母串内术语覆盖范围排除。
  未启用术语检查时不排除；空参考译文术语和输入文件中遗留的“术语表”也不作为排除依据。
- Source / Target 分组和匹配前应用[共享归一化规则](../../docs/consistency-normalization.md)；报告仍保留原文。
  归一化后相同的 Source 不属于子串关系，继续由“同 Source 不同 Target”负责。
- 只将具有唯一、非空参考 Target 的 Source 用作短句参考。重复 Source 的 Target
  按归一化后的文本比较；存在不同译文（包括空值与非空值）时整个 Source 组不作为参考。
  该冲突规则不依赖另一项检查是否开启；冲突组仍可以作为被检查的长句。
- 归一化后为空的 Source 跳过；归一化后为空的长句 Target 跳过，本检查不承担未翻译检测。
- 归一化后的参考短句去除常见 `<...>`、`{...}`、`[...]`、printf 占位形式后，只统计
  文字与字母（Unicode `isalpha`），空白、标点和数字不计数。含有汉字、假名或韩文时
  使用 CJK 最小有效字符数，默认 **3**；其他文字默认 **2**，均可配置为 1–1,000,000。
  混合文本只要含有 CJK 文字也采用 CJK 下限，计数包含其中的其他字母。
  例如 `【阿童木】` 计 3 字，`合作`、`确认！` 只计 2 字，默认不作为参考。
  下限只限制子串候选，不限制母串，也不限制参考 Target 的长度；参考 Target 去除
  上述结构后须至少有一个文字或字母。纯数字、纯标点及仅含这些结构的文本不作为参考。
  这只是参考资格过滤，真正匹配时仍使用归一化后的完整文本，不删除 Tag 或占位符。
- Source 和 Target 均使用共享的 ASCII 词边界：以 ASCII 字母或数字开始/结束的
  片段，不能紧邻 ASCII 字母、数字或下划线。比如 `he` 不命中 `the`，`save` 不命中
  `saver`；中文片段允许连续匹配。这不是多语言分词或语义对齐。
- 归一化后的 Target 匹配忽略大小写（Unicode casefold），仍区分内部空格、换行、标点，不推断
  单复数、同义词、词形变化或语序调整。
- 保留所有有效短句关系，包括嵌套和重叠片段，不只检查最近父级。同一短句在同一长句
  中多次出现只核验一次。

## 报告与性能

统一报告 `问题处理` 定位到长句所在原始行，保留其完整 Source / Target，描述附上
`“短句原文” → “参考译文”（参考原表第 12 行）`，多个问题分行显示。
不认定哪一方译法正确，不自动替换译文；短句可通过参考行号定位。

每个长句行最多显示前 10 个疑似问题详情，每段参考 Source / Target 最多展示
120 个字符，每个参考组最多展示前 10 个行号。超限会明确标注省略；问题数量始终
统计全部有效关系，检查不会因展示限额提前停止。`质量检查汇总` 统计有问题的长句行数，
同一长句行有多个问题也只计一行。

术语条目在分组前排除，过短候选在建立索引前过滤，不重新读取历史 TB 文件。
使用项目已有的 `pyahocorasick` 分别为参考 Source 和 Target 建立索引；相同 Source
只扫描一次，相同 Source / Target 的重复行共享核验结果。逐个长句处理，不保存全局
包含图，也不展开重复短句与重复长句的行号笛卡尔积。命中位置过密时，切换为逐模式寻找
首个符合词边界的命中，避免同一片段反复枚举；恢复原有的首次命中顺序，描述及前 10 条
展示顺序不变。该切换只限制位置枚举，不限制候选、有效关系或问题数量。
高度重复的语料仍受参考数量和文本长度影响，不能仅按行数估计耗时。

业务实现位于同目录 `check_substring_consistency.py`，覆盖规则、边界、去重、截断与
朴素算法对照的测试位于 `tests/test_substring_consistency_checker.py`。
