# 一键质量检查与修订回填

一键质量检查把所选项目写入同一份 Excel 报告。统一入口为 GUI 的“一键质量检查”
或 `qatools qa`。

## 执行模型

- 所有选中检查共用一次主工作簿读取，在内存中依次执行并只保存一次。
- 历史 TB 是独立输入，仅在启用术语检查时额外读取。
- 不对同一工作簿并发写入，避免线程竞争、文件锁和输出损坏。
- 默认开启八项常用检查；“同 Target 不同 Source”和“子串译文一致性”默认关闭。
  新增检查的匹配、参考资格和报告截断规则见 [子串译文一致性](../substring_consistency_checker/README.md)。

检查名称、`--check` 值和规则入口统一维护在
[CLI 使用指南](../../docs/cli-usage.md#一键质量检查)。

## 使用

```bash
qatools qa input.xlsx -s Sheet1 -c A -t B
```

GUI 将检查分为“术语与翻译一致性”“内容保真检查”和“Target 文本质量”。术语、
子串译文一致性、Tag 和 Target 文本规范的详细设置通过各自右侧入口打开。
工作表首行的 Source / Target 列会自动识别；匹配优先级、冲突处理及自定义配置见
[GUI 表头别名设置](../../README.md#自定义表头识别)。

点击“全选 / 清空”旁的“记住选项”，可保存当前页面的全部选择：输入文件、工作表、
Source / Target 列、开始行、各检查的勾选，以及术语标记和历史 TB、Tag 模式和
顺序检查选项和过滤配置、子串最小有效字符数、Target 文本规范规则等详细设置。未勾选检查的详细设置也会保留。
下次打开 GUI 时自动恢复；后续调整只有再次点击“记住选项”才会更新保存内容。
选项保存在当前用户配置目录的 `Toolshub/workflow_options.json`（Linux 为
`toolshub/workflow_options.json`）；恢复时不读取 Excel，也不会自动开始检查。
重新选择输入文件后仍按该文件识别工作表及列。

## 统一报告

`问题处理` 的固定列为：

```text
行号, source, target, 修改后target, 问题描述, 检查项
```

- 同一原始行命中多个检查时只保留一行，检查项和问题描述会合并。
- 行顺序为“同 Source 不同 Target”在前、“同 Target 不同 Source”其次、其余
  问题按原始行号排列。前两类分别按[归一化后相同](../../docs/consistency-normalization.md)的 Source、Target 连续排列，各组
  按首次出现的原始行号排列；Source 组内归一化后相同的 Target 相邻，各译文版本按首次
  出现顺序排列，同一版本内按原始行号排列；Target 组内按原始行号排列。
- 同一行同时命中两类一致性检查时，优先排入 Source 组，只显示一次；两类问题
  及完整同组行号均保留。排序只影响展示位置，合并规则、问题内容与回填目标不变。
- 问题描述使用各检查生成的简洁格式，保留检查项前缀；不再重复追加已表达的专项字段。
  独立问题表的附加列保持不变，具体描述格式见各工具 README。
- `术语表` 会标出本批次有问题的术语；状态规则见[术语检查说明](../term_pair_checker/README.md#术语问题状态)。
- 点击行号会跳转到原数据工作表对应的 target 单元格。
- 最终报告保留原业务工作表，并包含可选的 `术语表`、`问题处理` 和
  `质量检查汇总`；各检查的临时问题表会在汇总后移除。

## 修订回填

1. 在 `问题处理` 的黄色 `修改后target` 列填写最终译文；留空表示忽略。
2. 保存报告，在 GUI 中点击“应用修订”。
3. 工具生成 `revised_<原文件名>`，不会覆盖检查报告。

回填按 `行号` 定位原数据行，并精确核对 `问题处理` 页的 `source` 与该行原文；
不匹配的行会跳过并在完成提示中列出。`问题处理` 页的原 `target` 仅供参考，修改
或清空它不会影响回填。即使原数据表中的 target 已变化，只要行号对应的 source
匹配，仍以 `修改后target` 为准；新值与当前数据表的 target 相同时计为内容未变化。
修订稿保留原业务工作表，只移除本次 workflow 生成的 `术语表`、
`问题处理` 和 `质量检查汇总`。

## 实现位置

统一 PySide6 页面在同目录 `qt_page.py`；页面注册、共享控件和对应测试见[仓库地图](../../docs/repository-map.md)。
`workflow_gui.py` 只保留打开该页面的启动转接。
QA 详细设置弹窗及取消恢复逻辑在 `qt_settings.py`；持久化选项在 `gui_options.py`。
