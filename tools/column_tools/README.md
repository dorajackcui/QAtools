# 列操作（Column Clear）

GUI【文件与表格 → 列操作】提供 momoTools 原 Column Clear 页中的三个动作。
业务层通过 Microsoft Excel 操作工作簿；CLI 尚未接入。

1. 选择文件目录。新输出目录为可选项：留空直接更新原文件，填写尚不存在的新目录时另存副本。
2. 选择清空、插入或删除，填写列字母（A–XFD）。默认 C 列。
3. 工作表留空使用各文件活动表，也可指定同名工作表。
4. 点击【执行列操作】，底部【查看日志】按文件显示单行结果和必要的失败原因，完成后显示摘要。
   输出目录只保留处理后的工作簿，不生成附加 report；详见[运行日志](../../docs/tool-logs.md)。

## 动作

- **清空列内容**：保留表头行和单元格格式，清空指定列中表头之后至实际已用区域末行的内容，
  包括公式。默认保留 1 行表头，可设为 0。UsedRange 起点不为第 1 行时仍计算正确末行。
  只有表头或空表时不建立逆向范围。
- **插入一列**：在指定列位置插入整列，其后各列右移；第 1 行写入用户填写的标题，默认 `Translation`。
  表头行数设置不影响此动作。
- **删除整列**：删除指定列（包括表头），其后各列左移，由 Excel 处理引用变化。

支持 `.xlsx/.xlsm/.xls`，递归处理并保留相对目录结构；`.xls` 列上限由 Excel 实际工作簿决定。
指定工作表不存在、保护阻止编辑或保存失败时记为该文件失败，继续其他文件。
先保存临时工作簿，成功后才替换原文件或生成副本；失败时保留原文件。工作簿、COM 会话和环境要求与
[兼容性重存](../excel_compatibility/README.md) 共用实现。
