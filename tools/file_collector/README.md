# 文件提取

GUI【文件与表格 → 文件提取】按文件名清单从来源目录提取整个 Excel 文件，适合准备待翻译、返修和交付文件。
文件在本机复制，不解析工作簿，不需要桌面 Excel。CLI 为 `qatools collect-files`，
完整调用见[CLI 手册](../../docs/cli-usage.md#文件提取)。

## 使用

1. 选择来源目录，粘贴文件名列表，或通过【导入 TXT】读取 UTF-8（允许 BOM）文本清单。
2. 指定尚不存在的新输出目录。选择来源时默认建议旁边的 `<来源目录名>_selected`，可以修改。
3. 默认平铺到输出根目录；勾选【保留来源目录结构】后按来源相对路径输出。
4. 点击【预览匹配】，查看清单项、来源相对路径、输出相对路径与状态，以及各项计数。
5. 点击【复制可用文件】，查看逐文件结果和【查看日志】；完成后可【打开输出目录】。

修改清单、路径或选项会清除旧预览。切换导航保留页面状态；扫描、TXT 导入、复核和复制均在后台进行，
任务期间禁用输入和重复提交，主窗口退出保护识别这些任务。

## 清单与匹配

- 默认按换行或 Tab 分隔，适合粘贴 Excel 单列。去掉首尾空白、空行及不区分大小写的重复项，保留首次输入顺序。
  文件名内部的空格、逗号保留；勾选【同时按中英文逗号分隔】才额外按 `,` / `，` 分隔。
- 只接受文件名，不接受目录路径、通配符或 Windows 非法文件名字符。
- 支持 `.xlsx/.xlsm/.xls/.xlsb`，不区分大小写。带受支持扩展名的输入按完整文件名匹配；
  不带这些扩展名的输入按文件主名匹配全部受支持格式。例如 `A.xlsx` 只匹配该格式，`A` 同时匹配 `A.xlsx` 和 `A.xlsm`。
  主名内部可以有点号，例如 `A.v2` 匹配 `A.v2.xlsx`。
- 递归扫描来源目录，跳过 `~$` 锁文件、`.qatools-backups`、可识别的历史结果目录、当前会话生成目录、
  符号链接及 Windows 重解析点（包括目录联接）。生成目录识别范围见[目录工具日志](../../docs/tool-logs.md#输出目录)。
- 同一个来源路径即使被多个清单项命中也只复制一次，预览保留全部关联清单项。
  无匹配项单独列为“未找到”，不计入匹配文件数。

## 重名与输出

- 平铺时，多份来源映射到同一输出文件名，会跳过该冲突组的所有文件，不选择第一个。
- 保留结构时，不同相对路径的同名文件可以全部复制。输出路径比较仍忽略大小写；
  大小写差异导致的路径碰撞，以及文件与目录之间的路径碰撞，也按冲突跳过。
- 输出目录必填，必须尚不存在，且来源与输出不能相同或互相包含。没有可复制文件时不创建输出目录。
  本工具没有原位模式，也不向已有输出目录追加文件。
- 成功复制保持文件字节及修改时间，来源内容不变；不复制无匹配文件，不生成附加报告或清单文件。
  逐文件日志和结果摘要保留在本次会话中，日志窗口支持复制。

## 预览复核与失败

- 复制前重新扫描并比较匹配结果，以及文件身份、大小、修改时间和元数据变化时间；
  匹配来源新增、删除或这些信息变化时，停止执行并要求重新预览，尚不创建输出目录。
  这是文件元数据复核，不是全文件内容哈希校验。
- 单文件写入先复制到输出位置的临时文件，再复核来源状态，最后以不覆盖已有文件的方式发布。
  即使其他程序在复制期间创建同名目标，也不会覆盖它；失败时清理本次临时文件。
- 开始复制后的单文件错误不会阻止其他可用文件；已成功输出保留。运行结果区分已复制、失败、跳过，
  未找到按清单项单独计数，失败原因可在表格状态的悬浮提示或日志中查看。
- 每份 GUI 复制计划只执行一次。失败或完成后如需再执行，应选择新输出目录并重新预览。

将处理好的文件替换回现有目录仍使用[同名文件替换](../deep_replace/README.md)。
