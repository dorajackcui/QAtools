# 同名文件替换（Deep Replace）

GUI【文件与表格 → 同名文件替换】按文件名匹配并搬运**整个 Excel 文件**，不合并工作表或单元格。
不需要 Excel、pandas；CLI 尚未接入。

1. 选择替换来源目录，以及需要被替换的目标文件目录。
2. 新输出目录默认留空，直接替换目标目录中的文件；填写尚不存在的新目录时生成目标 Excel 文件树副本。
3. 点击【替换同名文件】，底部【查看日志】可实时查看替换详情和最终摘要。
   输出目录不生成附加 report；日志规则见[运行日志](../../docs/tool-logs.md)。

## 匹配与输出

- 递归扫描 `.xlsx/.xlsm/.xls/.xlsb`，按完整文件名（包含扩展名）不区分大小写匹配。
  目录层级不参与身份；来源和目标不能相同或互相包含。
- 唯一来源对应唯一目标时才替换。同名来源或目标有多个时，跳过该名字下所有替换，日志列出候选路径。
  不任意挑选重名文件，也不把一个来源隐式覆盖到多个目标。
- 原位模式只替换匹配项，无匹配或冲突项不动。填写新输出目录时生成目标 **Excel 文件树**
  的副本：匹配项使用来源文件，无匹配或冲突项复制目标文件。
  非 Excel 文件不复制。来源中没有对应目标的文件仅在日志列出，不新增进目标树。
- 跳过 `~$` 锁文件、`.qatools-backups` 备份树、另存输出及本次应用会话已生成的结果子目录。
  先固定候选清单，再开始写入。
- 所有复制使用临时文件和原子替换，不解析或改变工作簿内容；成功输出与选中的来源文件字节一致。
- 单文件失败不阻止其余文件，摘要区分实际替换、保留、冲突跳过和失败。

## 原位替换及恢复

输出留空即为原位替换，不再需要额外勾选。每次运行采用独立的备份子目录，
替换前先将原文件备份到 `<目标目录>/.qatools-backups/deep-replace-<唯一名称>/<相对路径>`。
备份失败则不进行替换；没有匹配项时不创建备份。重复运行不会把备份枚举为目标。
替换失败时原子操作保留目标原内容，备份保留供检查；成功后备份也不会删除。

如需撤回成功替换，将对应运行备份目录中的文件按相对路径复制回目标目录；日志每次显示一次备份目录，
每个文件的单行结果标记“已备份”，备份文件位于该目录下的同一相对路径。
本期不提供单独恢复按钮。来源文件始终不改动，已完成的替换与备份保留在各自位置。
