# 内容保真检查

逐行比较 Source 与 Target 中无需翻译或不应被意外修改的内容。当前包含
`数字一致性`和 `URL 一致性`两项规则，通过一键质量检查 GUI 或 `qatools qa`
使用。

## 数字一致性

- 提取半角或全角阿拉伯数字，并把全角形式规范为半角后比较。
- 日期、时间、版本号、范围、百分比等连续数字表达式作为整体比较。
- 比较时不要求顺序一致，但保留重复次数。
- URL、已识别的 Tag、Placeholder、memoQ Marker 和字符编码转义内的数字不参与
  本规则，避免与专项检查重复报告。
- 数字中的小数点、千位符、正负号和百分号属于数字内容的一部分。

## URL 一致性

- 识别 `http://`、`https://`、`ftp://`、`file://`、`mailto:` 和 `www.` 开头的 URL。
- URL 按完整文本和重复次数精确比较，不要求出现顺序一致。
- URL 后属于句子的逗号、句号等标点，以及不成对的右括号，不计入 URL。

## CLI

```bash
qatools qa input.xlsx -c A -t B --check number --check url
```
