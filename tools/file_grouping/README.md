# 文件分组

GUI【文件与表格 → 文件分组】按共同的待翻译原文把完整 Excel 文件归为文件群，方便在派发前避免同一句段落在不同译员手中。此工具仅提供 GUI，不新增业务 CLI 命令。

## 使用

1. 选择来源目录，填写原文、译文表头，默认 `MsgStr` 和 `fr`。
2. 点击【扫描分组】，查看分组、文件数和去重中文字数。
3. 点击组名或选中后按回车，查看组内相对文件路径。同群文件建议一起分配；“其他”中的文件可以分别分配。
4. 点击【导出分组…】，选择保存位置。工具新建 `<来源目录名>_文件分组_<时间>` 目录，按 `文件群1/`、`文件群2/`……及 `其他/` 复制完整文件，每组内部保留来源相对目录结构。

界面只保留来源目录、两项表头、分组表和扫描 / 导出操作，不指定译员或分包数量。
切换导航保留输入与结果；修改任一输入会清除旧分组。扫描、复核、复制在后台运行，期间禁用输入与重复提交，主窗口退出保护识别这些任务。

## 扫描与分组规则

- 递归读取 `.xlsx/.xlsm`。忽略 `~$` 锁文件、`.qatools-backups` 备份树、可识别的历史结果目录、本次会话生成目录、符号链接和 Windows 重解析点。生成目录识别范围见[目录工具日志](../../docs/tool-logs.md#输出目录)。
- 遍历工作簿中的所有工作表，包括隐藏表。表头在首行，去首尾空白后按用户填写的名称精确匹配，区分大小写。两项表头必须不同且各自唯一；同时不含这两个表头的说明表忽略。仅有一个表头、表头重复、整份工作簿没有匹配表头均报错。
- 只比较原文非空、译文为空的行。空值包括 `None`、纯空白和浮点 NaN；文本 `nan`、`None`、数值 0、False 均视为有效内容，不视为空值。
- 原文转换为字符串后精确比较，保留首尾空白、大小写、换行和标点，不做模糊匹配。所有有效原文均参与分组，包括中文字数为零的原文。
- 以文件为单位：A 和 B 有共同的待翻译原文，B 和 C 又有共同原文，则 A、B、C 同属一个文件群。不会拆分工作簿、工作表或行。
- 多文件群按文件数量降序排列，数量相同按首个相对路径排序，依次命名为“文件群 1、2……”；数量自动决定。没有跨文件重复原文的文件汇总为“其他”，各文件仍独立。没有独立文件时不显示空的“其他”组。
- 完整扫描结果中，不同文件群之间、文件群与“其他”之间，以及“其他”内部各文件之间，没有相同的待翻译原文。已翻译行不在此保证范围内；同群中的每两个文件也不一定直接重复。
- 去重中文字数按组内待翻译原文去重后，累计 `U+4E00–U+9FA5` 字符数，不计标点、英文和数字。组间原文不重复，因此各组去重字数可以相加。
- 公式按公式本身读取，译文公式视为非空；待翻译原文包含公式时报错，需先转为值，避免把公式当作句段或把缺少缓存误判为空。工作簿只读并显式关闭。

## 错误与导出

- 损坏、缺少表头、无法读取和不支持的 `.xls/.xlsb` 文件列在【查看问题】中。失败文件不会归为“其他”或零工作量；扫描不完整时禁用导出，修正后重新扫描。
- 导出复制完整文件，保留文件字节及修改时间。源文件不修改，不生成额外工作簿或报告文件；保存成功后可从状态栏打开输出目录。
- 输出必须是新目录，不能与来源相同或互相包含，不覆盖已有文件。保留相对路径允许不同子目录的同名文件同时导出；忽略大小写后的输出路径冲突会在复制前报错。
- 开始导出前重新核对文件列表、文件身份 / 大小 / 时间和 SHA-256。来源新增、删除或变化时要求重新扫描，此时尚不创建输出目录。
- 每个文件先复制到临时文件，核对来源状态与复制内容后以不覆盖方式发布；复制期间创建的同名目标不会被覆盖。导出结束再次核对来源列表与内容。
- 导出期间出现错误立即停止，清理当前临时文件，保留已导出的文件并提示数量与位置。修正问题、重新扫描后导出到另一个新目录。

此工具用于发现可独立派发的文件群，不自动把文件群再平衡成固定数量的作业包。
