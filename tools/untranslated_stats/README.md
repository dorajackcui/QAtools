# 未翻译统计（Untranslated Stats）

GUI【翻译辅助 → 未翻译统计】统计目录内各工作簿的未翻译量和总量。
使用 openpyxl，不需要 pandas 或 Microsoft Excel；CLI 尚未接入。

选择文件目录，按需填写新输出目录，指定原文列、译文列、计数口径、工作表和表头行数，
点击【生成统计表】。默认原文 B、译文 C、活动工作表、1 行表头、中文字符数；
输出默认留空，将 `未翻译统计.xlsx` 保存到所选文件目录；填写尚不存在的新目录时另存统计表。
列配置手动指定，原文和译文列必须不同。

## 统计口径

- 原文为真实空值、纯空白或浮点 NaN 时不计入总行数；0、False 和其他有效内容计为一行。
- 译文为真实空值、纯空白，或去首尾空白后不区分大小写等于 `nan` 时，计为未翻译。
  文字 `None`、`NA`、`NULL`、数值 0、False 均视为已有译文。
  这里继承旧工具的统计口径；**内容同步始终保留文字 `nan`，不会把它当空值**。
- 中文字符数保留原范围 `U+4E00–U+9FA5`；标点、英文、数字及范围外汉字不计入。
- 英文词数使用 `\b[a-zA-Z]+(?:['\-][a-zA-Z]+)*\b`，如 `don't`、`re-use` 各计一词。
  有效原文即使计数为零，仍计入总行数。
- 读取公式的最近保存缓存，不重新计算。缓存为空的原文按空原文跳过，缓存为空的译文按未翻译处理；
  为获得准确统计，应先在 Excel 计算并保存含公式的数据。

## 文件与报告

- 递归处理 `.xlsx/.xlsm`；`.xls/.xlsb` 记为跳过，其他格式不参与。忽略 `~$` 锁文件、
  `.qatools-backups` 备份树、另存输出和本次应用会话已生成的结果子目录。输入工作簿只读并显式关闭。
- `未翻译统计.xlsx` 为本工具保留的结果文件名，递归扫描时排除该名称（包括旧统计表）。
  重复运行会先生成临时统计表，再替换同名旧结果；不会把统计表算入输入。
- 缺少配置列、指定工作表不存在、文件损坏等均计为失败，不把失败文件写成零工作量。
- `未翻译统计.xlsx` 的主工作表为 `未翻译统计`，列为：文件名、未翻译字数、未翻译行数、
  总字数、总行数；英文模式将“字数”替换成“词数”。文件名使用相对路径避免同名混淆，最后一行为总计。
- `未统计文件` 工作表按需列出失败/跳过文件、状态和原因。输出目录只生成统计工作簿，不附加 JSON report。
  所有文件失败时仍输出失败清单和仅含总计的主表，GUI 明确提示失败。
- 底部【查看日志】按文件显示单行计数（未翻译量/总量、未翻译行/总行数）或错误；具体行为见[运行日志](../../docs/tool-logs.md)。
- 输出保存失败时任务报错，输入不变。
