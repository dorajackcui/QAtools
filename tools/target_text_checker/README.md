# Target 文本规范检查

该检查集成在“一键质量检查”中，四条规则均可独立启用：

- `异常标点符号`：报告 `..`、`....`、`,,`、`，，`、`。。`、`：：`、`;;`、`；；`、`、、` 等连续标点；允许 `...`、`…`，不检查连续感叹号和问号。
- `连续空格`：报告 Target 任意位置的 2 个及以上普通 ASCII 空格，包括开头和结尾；单个空格和 NBSP 不纳入本规则。
- `首尾空格`：报告 Target 开头或结尾的一个或多个普通 ASCII 空格，不把 NBSP 纳入本规则。
- `全半角混用`：仅比较同类字符或标点，例如 `,`/`，`、`(`/`（）`、半角/全角字母和数字。英文单词与中文标点正常共存不会单独触发。

一键质量检查 CLI 中使用 `--check text` 启用该检查，并可重复传入
`--text-rule` 选择规则。未指定规则时默认运行全部四项。

原 CLI 规则名 `abnormal-ellipsis` 仍可使用，并会映射到升级后的
`abnormal-punctuation` 规则。

## 问题描述

描述直接列出问题和命中内容，例如 `异常标点：“。。”`、`连续空格：3 个`、
`头部空格：1 个；尾部空格：2 个`。全为空格时显示 `首尾空格：3 个`；全半角混用
显示具体字符，例如 `全半角混用：逗号（半角 , / 全角 ，）`。独立问题表的
“问题类型”和“命中内容”列保持不变。
