# Target 文本规范检查

该检查集成在“一键质量检查”中，五条规则均可独立启用：

- `异常标点符号`：报告 `..`、`....`、`,,`、`，，`、`。。`、`：：`、`;;`、`；；`、`、、` 等连续标点；允许 `...`、`…`，不检查连续感叹号和问号。
- `连续空格`：报告 Target 任意位置的 2 个及以上普通 ASCII 空格，包括开头和结尾；单个空格和 NBSP 不纳入本规则。
- `首尾空格`：报告 Target 开头或结尾的一个或多个普通 ASCII 空格，不把 NBSP 纳入本规则。
- `全半角混用`：仅比较同类字符或标点，例如 `,`/`，`、`(`/`（）`、半角/全角字母和数字。英文单词与中文标点正常共存不会单独触发。
- `括号与引号配对`：检查 Target 正文中的括号和双引号是否闭合、顺序与嵌套是否匹配，规则见下文。

一键质量检查 CLI 中使用 `--check text` 启用该检查，并可重复传入
`--text-rule` 选择规则。未指定规则时默认运行全部五项。

原 CLI 规则名 `abnormal-ellipsis` 仍可使用，并会映射到升级后的
`abnormal-punctuation` 规则。

## 括号与引号配对

- GUI 中为一个独立开关，默认开启；CLI 规则名为 `paired-symbols`。
- 检查 `()`、`（）`、`[]`、`［］`、`【】`、`{}`、`｛｝`、`“”`、`«»` 和普通双引号 `"`。
  普通双引号按先开后闭处理；跨行但仍在同一单元格内可以配对，不跨单元格配对。
- 检查缺少左符号、缺少右符号、类型不匹配及交叉嵌套，例如 `)(`、`（text)`、`([)]`。
- 不检查直单引号 `'`、弯单引号 `‘’`；`l'orage`、`l’orage`、`don't` 等不会因撇号触发本项。
- 排除已识别的 `<...>`、`[color=...]`、`[/color]`、`{...}`、`{{...}}` 和 memoQ Marker
  内部符号，识别范围沿用 [Tag / Placeholder](../tag_placeholder_checker/README.md)。
  memoQ Marker 包裹的正文仍检查。未识别的残缺片段不会整段排除；普通尖括号 `< >` 不作为正文配对符号。
- 本项仅判断 Target 自身，不比较 Source 的符号数量，也不解析特定语言的其他引号习惯或转义语法。
- 同一行本规则的多个问题合并为一条，描述注明符号、从 1 开始的原文字符位置和缺少/期望的配对符号。
- 无待检查符号的文本直接跳过；含符号时才识别 Tag / Placeholder，沿用主工作簿读取和保存，不增加 Excel 文件读写次数。

## 问题描述

描述直接列出问题和命中内容，例如 `异常标点：“。。”`、`连续空格：3 个`、
`头部空格：1 个；尾部空格：2 个`。全为空格时显示 `首尾空格：3 个`；全半角混用
显示具体字符，例如 `全半角混用：逗号（半角 , / 全角 ，）`。独立问题表的
“问题类型”和“命中内容”列保持不变。
